## 🎮 How to Enter Cheat Codes in GTA 6

In *Grand Theft Auto VI*, cheat codes operate under specific single-player Story Mode rules:

1. **Beat the Main Story (91 Missions):** Unlike previous GTA games, cheats are not available from Mission 1. You must beat the 91-mission main story campaign to unlock the **Cheats** section inside the **Progress** menu.
2. **Complete Cheat Challenges:** Each specific cheat requires completing an in-game challenge (e.g., destroying 50 cocaine flamingos or completing specific stunt jumps) before activation is granted.
3. **Controller Input Activation:**
   - Stand in single-player free roam.
   - Press **D-Pad Up** to pull up your character's in-game smartphone.
   - **PlayStation 5:** Hold **L1** and press **R1**, then input the directional D-Pad sequence.
   - **Xbox Series X|S:** Hold **LB** and press **RB**, then input the directional D-Pad sequence.
   - Or open the phone dialer and dial the cheat's cell phone number.

> ⚠️ **Warning on Trophies & Saving:** Activating any cheat code disables PlayStation Trophies and Xbox Achievements and blocks game saving for your current session. Always create a manual backup save before using cheats.
